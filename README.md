# わんごはん計算機 🐾

## 公開URL

https://ogd328.github.io/wan-gohan-calculator/

愛犬の体重管理と、手持ちのフード・おやつの給与量を計算するWebアプリです。
**`index.html` 1ファイルで完結**し、ブラウザで開くだけで使えます（ビルド・サーバー不要）。

## 主な機能

- **体重から1日のカロリーを計算**
  - 犬種・現在体重・目標体重を入力
  - **純血種に加えてミックス犬にも対応**（2犬種の掛け合わせを選ぶと、成犬体重の推定レンジ（目安）から計算）
  - 「しっかり」モード：年齢（子犬2段階／成犬／高齢犬）・避妊去勢・活動量から計算（RER × 係数）
  - 「かんたん」モード：犬種サイズ別の kcal/kg でサッと計算
- **おやつを複数種類登録**
  - 手持ちのおやつを種類ごとに追加し、それぞれ「何個まであげていいか」を表示
  - 1個あたりkcal／100gあたりkcal＋1個の重さの両方に対応
  - おやつの合計が1日の10%以内になるよう案内
- **フードの給与量を計算**
  - 手持ちのフードの kcal/100g を入力（または商品を選択）
  - おやつ上限（1日の10%）を差し引いたフード量、おやつなしの場合、1回あたり（1日2回）を表示
  - フードの残り量を入れると「何日分か」も計算
- **犬種に合うフード候補を表示**
  - 犬種サイズ・年齢で絞り込んだ代表的なフードを4件カード表示
  - タップで kcal を自動入力。32商品を収録（2026年11月時点、公式ページの代謝エネルギー確認値）
  - 候補にないフードは手入力可
- **減量・増量プラン**
  - 週1〜2%の安全ペース、かかる期間、到達目安を表示
  - 目標体重のRER（減量）／維持の15%増（増量）で給与カロリーを計算
- **体重のきろく**
  - 日付と体重を記録すると、目標ライン付きの折れ線グラフを表示
  - データはブラウザ内（localStorage）にのみ保存。リロードしても復元
- **その他**
  - スマホ対応、計算結果のコピー、印刷・PDF保存
  - 入力内容は自動保存

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く
2. 犬種（純血種／ミックス犬）・現在の体重・目標体重を入力
3. 手持ちのフードを選ぶ（わからなければ候補カードをタップ）
4. おやつのカロリーを入力
5. 右側（スマホでは下部）の計算結果を確認

## 計算の考え方

| 項目 | 内容 |
|---|---|
| RER（安静時エネルギー要求量） | 70 × 体重(kg)^0.75 |
| 維持カロリー（しっかり） | RER × 係数（避妊去勢済み成犬1.6／未避妊1.8／子犬3.0・2.0／高齢犬1.4）× 活動量補正(0.9〜1.15) |
| 維持カロリー（かんたん） | 体重 × サイズ別kcal/kg（超小型80／小型68／中型57／大型48） |
| 減量中 | 目標体重のRER × 1.0 |
| 増量中 | 目標体重の維持カロリー × 1.15 |
| おやつ上限 | 1日カロリーの10% |
| 減量・増量ペース | 体重の1〜2%／週 |
| ミックス犬の体重目安 | 両親の成犬体重レンジの平均から推定（個体差が大きいため目安） |

## データ

- フード **32商品**（ロイヤルカナン、ピュリナ プロプラン、プロマネージ、グラン・デリ、愛犬元気、ヒルズ、ニュートロ、カナガン、アカナ、オリジン、アイムス、ペディグリー）
- 犬種 **24種**（体重目安つき）
- 出典：各メーカー公式商品ページの「代謝エネルギー」表示、WSAVA Global Nutrition Guidelines、AAHA 2014 Weight Management Guidelines、Ohio State University VMC、Pawlov犬種比較表ほか
- 開発用のデータやテストは非公開で管理しています。

## 注意

- 計算は一般的な目安です。持病のある犬、妊娠・授乳中の犬、成長期の子犬は獣医師に相談してください。
- フードのカロリーは商品改定で変わります。必ずパッケージ記載の「代謝エネルギー」を確認してください。
- 体重記録はブラウザ内にのみ保存され、外部送信は行いません。
